使用指南

快速上手
Mc_comer Mod

Mc_comer Mod 是一款 Cheat Engine 7.6 辅助工具，帮助你快速加载 Mod 文件并自动配置 CE 环境。帮助我的世界开发者快速建立外挂环境，以便测试反作弊。

1

下载与安装

前往 GitHub Releases 下载最新版本的 Mc_comer Mod 安装包，运行即可使用，无需额外配置。

2

登录验证

  • 运行程序后进入登录页面
  • 在密码框输入访问密码
  • 点击「登录」按钮进入主界面
3

打开 Mod

  • 点击「打开Mod」按钮加载 CT 文件
  • 程序自动查找并调用 Cheat Engine
  • 成功启动后显示「已启动 CE」状态
  • 需要先安装 CE 环境才能使用此功能
4

安装 CE 环境

  • 点击「安装CE环境」按钮
  • 自动将 Cheat Engine 7.6 解压到桌面
  • 等待解压进度完成
  • 安装成功后按钮变为「已安装」状态
!

自动更新检查

程序启动时会自动连接服务器检查新版本。如有更新，将弹出提示窗口 —— 你可以选择「开始更新」跳转到下载页面，或点击「不更新」停止更新行为。
