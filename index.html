功能特性

为何选择
Mc_comer Mod-py？

我们专注于底层技术实现，从 C 语言原生引擎到混合架构设计，每一个细节都追求极致性能。

🔐

C 原生引擎 100x+

全部热路径（AOB 模式扫描、内存读写、指令流刷新）由 C DLL 原生执行，Python 仅做编排调度，性能比纯 Python 方案提升 100 倍以上。

🔄

全局热键系统

基于 Windows GetAsyncKeyState 底层 API 实现的无窗口热键轮询，绑定信息自动持久化到桌面配置文件，支持所有功能模块的热键自定义。

🎨

智能更新检测

启动时自动连接服务器检查新版本，支持增量更新日志展示，让你第一时间体验最新功能。

🔧

多架构支持

支持 Hook 注入、NOP 替换、短跳转修改、单字节修改、按键模拟等多种底层修改技术，覆盖主流内存修改场景。

🛡️

密码+QQ扫码双登录

支持密码登录和 QQ 扫码登录两种方式，满足不同用户的使用习惯，保障访问安全。

🚀

Nuitka 原生编译

采用 Nuitka 将整个 Python 项目编译为 x64 原生机器码，启动速度快，运行无 Python 环境依赖。

使用指南

快速上手
Mc_comer Mod-py

Mc_comer Mod-py 是一款采用 C 语言 + Python 混合架构的内存工具，底层引擎由纯 C 编写，前端由 Python + 原生 Web 技术驱动。适用于需要底层内存操作的各种调试和测试场景。

1

下载与安装

前往 GitHub Releases 下载最新安装包，解压后直接运行，无需安装任何额外环境。

2

登录方式

  • 启动程序后进入登录页，支持「密码登录」和「QQ 扫码登录」两种方式
  • 密码登录：输入访问密码，回车或点击登录
  • QQ 登录：点击获取二维码，使用手机 QQ 扫码即可
  • 验证通过后进入主界面
3

进程连接

  • 先启动目标 Windows 进程
  • 在程序内点击「连接游戏」自动扫描连接
  • 连接成功后自动开启自动模块
  • 手动模块可在 UI 中自由开关
4

热键与更新

  • 每个手动模块可绑定全局热键，设置后自动持久化到桌面配置文件
  • 启动时自动检查更新，弹窗展示更新日志
  • 支持直接下载、QQ 群下载、官网下载三种获取方式
!

自动更新检查

程序启动时会自动连接服务器检查新版本。如有更新，将弹出更新窗口展示更新日志，并提供「直接下载」「QQ下载」「官网下载」三种更新方式。
